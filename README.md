# IBM-HR-Attrition-Analytics
Analyzed IBM HR data (1,470 employees, 35 features) using Python, SQL &amp; Power BI to uncover a 16.1% attrition rate. Overtime employees are 3× more likely to leave and leavers earn $2,046 less/month. Includes Jupyter cleaning notebook, SQL analysis, and a 3-page interactive Power BI dashboard.
